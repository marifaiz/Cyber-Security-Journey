# Cyber-Security-Journey
A collection of my technical write-ups, labs, and projects as I transition from Web Development to Cybersecurity.


## Projects

- **[Home Network Security Audit & Hardening](./Projects/home-network-security-audit/)**
  A hands-on security audit of my home router (Huawei HG8145X6-10). Identified and
  fixed default credential issues, investigated an anomalous connected-device count
  and traced it to MAC address randomization, and evaluated additional hardening
  controls with documented risk-based decisions. Applies concepts from the Google
  Cybersecurity Certificate in a real environment.
